### [Archived Survey]

https://arxiv.org/abs/2402.05121


테이블은 이차원 구조로 많은 데이터를 저장하며, 데이터베이스 질의, 스프레드시트 조작, 웹 테이블 질문 응답, 이미지 테이블 정보 추출 등 다양한 일상 작업에서 중요한 역할을 한다. 대형 언어 모델(LLMs)과 시각 언어 모델(VLMs)을 사용해 이러한 테이블 작업을 자동화하면 당연하게도 여러 분야에 큰 이익을 제공하며, 학계와 산업계의 주목을 받고 있다고 한다(잘 모른다). 이 서베이 페이퍼는 테이블 관련 작업과 그에 따른 사용자 시나리오 / 기술적 측면을 포괄적으로 검토하며, 전통적인 작업인 테이블 QA 뿐만 아니라 스프레드시트 조작(증강), 테이블 데이터 분석 등 새로운 분야도 다룬다. 또한, LLM과 VLM을 테이블 처리에 맞게 훈련시키는 기법과 LLM 기반 에이전트를 사용하는 프롬프트 엔지니어링을 논의하고, 사용자 의도 파악 및 다양한 테이블 출처에서 정보 추출과 같은 주요 도전 과제를 강조한다.


서베이 페이퍼인 만큼 위에서 아래로 순서대로 차근차근 살펴보려 한다.



## 1 Introduction



이 데이터 중심의 시대에, 대량의 데이터가 표의 형태로 구조화되어 저장되고 있다. 데이터베이스 질의, 스프레드시트 조작, 웹 테이블에서의 QA Task, 이미지 테이블에서의 정보 추출 등 일상적인 작업들이 우리의 일상생활에서 흔하게 일어난다. 이러한 작업들 중 일부는 지루?하고(반복적이고) 오류가 발생하기 쉬우며, 다른 몇몇 작업들은 전문적인 기술을 필요로 하므로 더 널리 접근 가능하도록 간소화될 필요가 있다. 테이블과 관련된 작업의 자동화는 일반 대중에게 상당한 이익을 제공하며, 학계와 산업계의 큰 관심을 받고 있다.

  

최근, 대형 언어 모델(LLMs)은 다양한 작업에서 그 효과성과 다재다능함을 입증하며, 자연어 처리 분야에서 중요한 진전을 이루었다 [5]. 이러한 성공은 연구자들이 LLMs를 테이블 관련 작업에 적용하는 것을 조사하게 했다. 그러나 테이블의 구조는 일반적으로 LLM 사전 훈련에 사용되는 평문 텍스트와는 다르다. 자연어 코퍼스와는 달리 [6], 테이블은 고유한 특성을 가지고 있다.

  

•  **구조화된 데이터:** 테이블은 본질적으로 구조화되어 있으며, 행과 열로 구성되고 각 열은 데이터의 의미와 상호 관계를 나타내는 스키마를 가지고 있다. 사람들은 테이블을 수직 및 수평으로 쉽게 해석할 수 있지만, 주로 순차적인 텍스트 데이터를 훈련하는 LLMs는 테이블의 다차원적 측면을 이해하는 데 어려움을 겪는다.

•  **복잡한 추론:** 테이블 처리 작업은 종종 비교나 집계와 같은 수치 연산, 열 유형 주석 달기나 결측값 감지와 같은 데이터 준비, 기능 엔지니어링이나 시각화와 같은 보다 정교한 분석을 요구한다. 이러한 작업은 복잡한 추론과 문제를 여러 단계로 분해하는 능력, 논리적 작업을 요구하여 기계 지능에 큰 도전을 제시한다.

•  **외부 도구 활용:** 실제 시나리오에서 사람들은 Microsoft Excel, Python, SQL과 같은 전문 도구를 사용하여 테이블과 상호 작용하는 경우가 많다. 효과적인 테이블 처리를 위해 LLMs는 이러한 외부 도구를 통합하고 사용하는 데 능숙해야 한다.

  

테이블 처리 작업이 제시하는 이러한 고유한 과제들은 LLMs를 이러한 특정 목적에 맞게 조정할 필요성을 강조한다. 초기 연구인 TaBERT [7], TaPas [8], TURL [9], TaPEx [10] 등은 테이블에 대해 신경망 언어 모델을 사전 훈련하거나 미세 조정하는 패러다임을 따랐다. 이들 방법은 위치 임베딩, 주의 메커니즘, 사전 훈련 작업을 위한 학습 목표를 포함하여 모델 아키텍처를 조정한다. 이러한 접근법들은 좋은 결과를 도출하지만, 주로 테이블 질문 응답(table QA)이나 사실 검증과 같은 특정 테이블 작업에 국한된다. 또한, 이들이 사용하는 BERT나 BART 모델은 더 넓은 범위의 테이블 작업을 처리하기에는 충분히 크거나 다재다능하지 않다. 최신 LLM 기반 접근법은 테이블 작업을 두 가지 주요 방식으로 해결한다: (1) 테이블 데이터셋을 선별하고 테이블 모델을 사전 훈련하거나 미세 조정 [11, 12, 13]; (2) LLM의 강력한 추론 능력을 활용하여 테이블 데이터를 이해하는 LLM 기반 에이전트를 활용하거나 LLM을 프롬프트 [14, 15, 16, 17]. 이러한 새로운 방법들은 명령 조정 [18], 맥락 내 학습 [19], 사고의 연쇄(chain-of-thought) 추론 [20], 자율 에이전트 [21]와 같은 LLM-specific 기술들을 활용하여 테이블 처리를 보다 다재다능하고 포괄적으로 접근한다.

  

이 설문조사의 주요 기여는 최근 제안된 스프레드시트 조작 및 데이터 분석을 포함한 다양한 테이블 작업의 광범위한 범위를 다루는 것이다. 또한, 명령 조정과 LLM 기반 에이전트 접근법에 초점을 맞춰 최신 LLM 사용 패러다임에 따라 방법들을 분류한다. 우리는 https://github.com/godaai/llm-table-survey 에서 접근할 수 있는 논문, 코드, 데이터셋과 같은 리소스를 수집한다.
